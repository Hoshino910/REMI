# @dsh-memory/dsh-adapter

DeepSeek Harness adapter for `session/event` observation, transparent runtime-context windows, optional inference-only affect prompting through DSH, a stable memory policy, extractive custom compaction, and JSONL telemetry.

See the repository root README and `examples/deepseek-harness` before mounting it. Only one compaction provider may exist in a Cordis realm.
